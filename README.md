## 보는 방법

`index.html` 을 더블클릭하면 브라우저에서 바로 열립니다.

로컬 서버로 볼 때는 이 폴더에서 아래를 실행하고 `http://localhost:8081/index.html` 을 엽니다.

```
python serve.py 8081
```

`spec.css` · `spec.js` 는 사내 기획서 템플릿 공통 파일입니다.
